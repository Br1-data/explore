# Segnale Remoto

Survival/crafting co-op in 3D low-poly per 2-4 amici, giocabile da browser e da PC (cross-play).
Il design completo è in [`docs/GDD.md`](docs/GDD.md).

## Sviluppo

```bash
npm install
npm run dev      # server su :2567 + client Vite su http://localhost:5173
npm run check    # formattazione, lint, typecheck, test
```
